# Adapt Cloud Applied AI Engineer Residency

The residency converts development skill and Claude architectural knowledge into evidence-backed delivery competence.

## Weeks 1–2: Foundation

Complete CCA-F preparation, run the repository locally, trace the workflow, and explain its trust boundaries.

## Weeks 3–4: Repository delivery

Use Cursor or Claude Code to complete a bounded issue through a reviewed pull request with tests and rollback notes.

## Weeks 5–6: Agent implementation

Add one read-only capability with deterministic policy, evaluation cases, failure handling, and cost telemetry.

## Weeks 7–8: Cloud operations

Deploy a synthetic-data environment using managed secrets, least privilege, CI/CD, logs, alerts, and a tested rollback.

## Weeks 9–10: Governance and FinOps

Produce a threat model, data-flow map, model and dependency inventory, SBOM, evaluation results, and token-cost analysis.

## Weeks 11–12: Client simulation

Run discovery, write the recommendation and delivery backlog, demonstrate the system, answer an adversarial review, and deliver an evidence pack.
