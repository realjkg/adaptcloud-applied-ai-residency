# Client-readiness rubric

| Competency | Points |
|---|---:|
| Software engineering and automated testing | 20 |
| Claude architecture, tool use, RAG/MCP, and evaluations | 20 |
| Security, privacy, and least privilege | 20 |
| Cloud deployment, CI/CD, and operability | 15 |
| AI Tokenomics and FinOps | 10 |
| Discovery and business understanding | 10 |
| Documentation and client presentation | 5 |

Client-ready requires at least 80/100, no critical security finding, no untested consequential tool action, a clean-environment deployment, demonstrated failure recovery and rollback, and a defensible explanation of value and operating cost.
